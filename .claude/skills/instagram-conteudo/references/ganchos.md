# Fórmulas de gancho

Use fórmulas diferentes ao gerar as 5 opções. Adapte ao vocabulário do público.

| # | Fórmula | Modelo |
|---|---|---|
| 1 | Erro comum | "Você está fazendo X errado (e nem percebe)" |
| 2 | Número + resultado | "3 passos para <resultado> sem <objeção>" |
| 3 | Contraintuitivo | "Pare de <conselho popular do nicho>" |
| 4 | Antes/depois | "Eu <situação ruim>. Hoje <situação boa>. O que mudou:" |
| 5 | Pergunta-dor | "Por que <dor> continua acontecendo mesmo quando você <esforço>?" |
| 6 | Mito x verdade | "<Crença comum>? Mito." |
| 7 | Lista salvável | "Guarde esse post: <N> <recursos/ferramentas/frases> para <objetivo>" |
| 8 | Segredo de bastidor | "O que ninguém te conta sobre <tema>" |
| 9 | Identificação | "Se você <comportamento específico>, isso é pra você" |
| 10 | Comparação | "<Opção A> vs <Opção B>: qual vale mais pra <público>?" |
| 11 | Urgência honesta | "Antes de <ação/data>, leia isso" |
| 12 | Desafio | "Aposto que você não sabe <fato do nicho>" |

## Critérios para escolher

- Específico > genérico ("R$ 300" > "dinheiro").
- Fala com **uma** pessoa do público, não com "todo mundo".
- Cria uma lacuna que só o conteúdo fecha — sem ser clickbait que o corpo não entrega.
- Respeita o compliance do nicho (sem promessa de resultado garantido).
